气象站基础与简易方法

班级气象站 PBL · 课堂探究卡片

一、我们要测哪些数据？

数据含义对"体育课建议"的作用
气温（℃）空气冷热太热(>35℃)建议避开暴晒
湿度（%）空气干湿闷热时运动易中暑
降水概率（%）下雨可能性>50% 建议室内或带伞
风速空气流动快慢大风天不宜投掷类活动
气压（hPa）空气"重量"连续下降常预示变天
天气现象晴/阴/雨/雪最直观的判断依据

二、去哪拿数据？免费数据源

首推：Open-Meteo（https://open-meteo.com）——完全免费、无需注册、不用 API Key，最适合课堂。直接拼一个网址就能拿到 JSON 数据，初中生也能用。
  • 和风天气 / 彩云天气：国内数据细，但需要注册拿到 API Key（适合进阶组）。
  • 中国天气网：可直接查，但机器读取不方便。
  • 手机天气 App：无编程时，人工读数填表也完全可行。

三、API / API Key / JSON 是什么？

🏦 类比（来自 QuickClass 苏格拉底引导）：天气数据像一个"天气银行"。程序想去取数据，得先有张"卡"——这张卡就叫 API Key。网站地址（URL）是"银行地址"，返回的一串文字（JSON）就是"吐出来的钞票清单"。

JSON 长这样（一看就懂）：

{
  "temperature": 26.5,
  "humidity": 70,
  "precipitation_probability": 40
}

程序读 JSON，就是从中"取出" temperature 等数值，显示到网页上。

四、"体育课建议"怎么算？

最简单的规则（数据处理组可用）：
• 若 降水概率 > 50% → "建议室内活动 / 记得带伞"
• 若 气温 > 35℃ 或 < 0℃ → "避免剧烈运动，注意防暑/保暖"
• 若 风速过大 → "不宜投掷、球类 outdoor"
• 否则 → "天气不错，正常户外体育课 🟢"

五、两条路线（按小组能力选）

路线 A · 编程版（信息科技融合）：数据获取组用 Open-Meteo 取数 → 数据处理组解析 JSON、算建议 → 前端展示组用 HTML+JS 做一个网页，显示实时数据和"体育课建议"按钮。

路线 B · 无编程版（人人可上手）：用温度计、湿度计、雨量筒在校园实测，或读手机天气 App，把数字填进「资源 4 记录表」，再用 Excel/画图工具做一周曲线。数学统计、语文报告照做。

💡 老师提示：零基础班级建议全员走路线 B 打底，有编程兴趣的小组再挑战路线 A；两组最后都要交"数据+分析+建议+报告"，正好覆盖数学与语文。
