# 示例 DEMO：真实生成的 PBL 资源包

本目录放了两个用 `quickclass-pbl-generator` 技能**真实生成**的成品资源包，供你直接打开预览、或直接拿来上课参考。

## 1. 校园噪音调查（六年级）

文件夹：`校园噪音调查/`

- 驱动性问题：「我们校园里哪里最吵？怎么让校园更安静？」
- 包含 5 个 HTML：`index.html`（导航）+ `01_噪音科普文章` + `02_分贝测量基础知识` + `03_国内外降噪案例` + `04_噪音数据记录表`
- 案例（均联网核实）：重庆东水门小学「声」态治理、南京静音操场相控阵、芬兰 Loimaa 学校声学改造
- 该包生成于技能「HTML 单格式」阶段，故只有 HTML 版

## 2. 班级气象站（初中 · 信息科技 + 数学 + 语文）

文件夹：`班级气象站/`

- 驱动性问题：「天气预报有时不准，我们能否自己建一个班级气象站？」
- 包含 5 个 HTML + `md/` 子目录 5 个 Markdown
- 案例（均联网核实）：石家庄二十七中 Arduino 数字气象站（省一等奖）、NASA GLOBE 计划、美国 Cedar Grove 小学实测 vs 预报对比
- `md/` 下的 `.md` 文件**可直接拖进 QuickClass 知识库**（QuickClass 知识库只收 `.md/.markdown/.txt`）

## 怎么用

- 课堂展示 / 打印：浏览器打开对应 `index.html`，数据表页点「打印 / 另存为 PDF」
- 上传知识库：把 `md/` 里的文件（或噪音包的 HTML 另存为 `.md` 后）拖进 QuickClass 知识库上传框
